# Приёмка GM platform

## Выполняемые офлайн-проверки

Из корня Barotrauma:

```powershell
dotnet LocalMods/LuaCsBuildSimulator/bin/Release/net10.0/LuaCsBuildSimulator.dll --mod "LocalMods/Primary package" --luacs "C:/Steam/steamapps/workshop/content/602960/2559634234" --out "Docs/PrimaryPackage/Verification/current" --compile-only
dotnet build "LocalMods/Primary package/Tests/GMPlatform/GMPlatform.csproj" -c Release
dotnet "LocalMods/Primary package/Tests/GMPlatform/bin/Release/net10.0/GMPlatform.dll" "LocalMods/Primary package"
dotnet "LocalMods/Primary package/Tests/GMPlatform/bin/Release/net10.0/GMPlatform.dll" --contracts . "Docs/PrimaryPackage/Verification/current/client/InternalsAwareAssembly.dll"
dotnet "LocalMods/Primary package/Tests/GMPlatform/bin/Release/net10.0/GMPlatform.dll" --contracts . "Docs/PrimaryPackage/Verification/current/server/InternalsAwareAssembly.dll"
python "LocalMods/Primary package/Tools/audit_gm_platform.py"
python "LocalMods/Primary package/Tools/analyze_emote_audio.py" --out "Docs/PrimaryPackage/Verification/emote-audio"
```

В текущей оболочке `dotnet run` завершался без вывода; запуск собранных DLL работает. Для сборки в ограниченной среде использовался локальный `DOTNET_CLI_HOME`, без изменения исходников SDK/движка.

* BuildSimulator проверяет компиляцию клиента и сервера против установленных сборок; `--compile-only` не запускает мод или игру.
* GMPlatform использует production-файлы ядра, траекторий и анимаций. Это проверки инвариантов, крайних случаев и численных свойств; счётчик включает выборки кривых, а не тысячи независимых игровых сценариев.
* Contracts загружает метаданные управляемых сборок без инициализации игрового движка. Проверяются точки Harmony, схема свойств, кодек `SceneWire` через настоящие сетевые сообщения, совпадение повторной сериализации и отклонение всех побайтовых усечений тестового пакета.
* Измерение ядра: 32 ожидающие сцены, тестовый адаптер, прогрев, 100 000 обновлений; CPU и GC текущего потока. Это не профилирование сервера, сети, звука, GPU или UI.
* Audio audit: хеши 25 неизменённых OGG, LUFS/peaks и сохранённые отчёты FFmpeg; waveform и spectrum `scream_f1.ogg` открыты визуально. Прослушивание не выполнялось, суммарная громкость реального микса не измерялась.

## Регрессионные инварианты

| Случай | Офлайн-доказательство |
|---|---|
| Дверь уже открыта при постановке | Не запускает сцену до нового фронта открытия |
| Одинаковые времена действий | Сохраняется заданный порядок |
| Изменение исходного черновика | Не меняет уже поставленную программу |
| Отзыв прав или удаление привязки | Ошибка прекращает будущие действия и отменяет ранее выданные временные эффекты |
| Ошибка целевого клиентского эффекта | Находится исполняющая сцена, прекращаются будущие действия |
| Два GM со старой ревизией | Старая запись/отмена отвергается, в том числе после удаления и повторного создания |
| Повторный вход во время cooldown | Не вызывает скрытый отложенный запуск, нужен новый фронт после паузы |
| Два эффекта одной лампы | Отмена/истечение одного не удаляет второй |
| Конец раунда | Чистые хранилища очищаются; клиентские подписки на конец раунда проверены статически |
| Галлюцинация при разных FPS | Численно совпадают скорость и положение при фиксированной цели |
| Имитация лагов | Вычислительное движение идёт; представление удерживает прошлый кадр и ghost |
| Условия, длительности, текст | NaN, неправильные диапазоны, небезопасный rich text и запрещённая широкая аудитория галлюцинации отвергаются |
| Кривые анимаций | Монотонность, конечность, соответствие аналитической скорости производной, точный срок окончания |
| Эмоции | Все варианты каталога дают конечные траектории; занятые руки, связывание и наложение действий отвергаются |
| Удар в конце звука | Времена ключей остаются упорядоченными без искусственного сдвига |
| Старые пресеты | Сохраняются времена, повтор и общая аудитория текста; неподдерживаемые несколько персональных целей явно отвергаются |
