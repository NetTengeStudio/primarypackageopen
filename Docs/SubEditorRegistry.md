Сверка от 2026-11-04. Эталон: `C:/Users/Admin/Documents/LuaCsForBarotrauma/Barotrauma`, прежде всего `BarotraumaClient/ClientSource/Screens/SubEditorScreen.cs`, `SubEditorCommands.cs` и реализации `MapEntity`, `ItemPrefab`, `Structure`, `Wire`, `ConnectionPanel`, `CircuitBox`, `Submarine`, `IdRemap`.

Этот реестр описывает реализацию и доказательства раздельно. Наследование от `SubEditorScreen` само по себе не доказывает работу функции в раунде.

- `CORE` — поведение проверено без движка в `Tests/SubEditorCore`.
- `ENGINE` — конкретный сценарий выполнен на установленных сборках игры в `Tests/SubEditorIntegration`, без игрового процесса.
- `PATCH` — целевой метод найден, патч действительно установлен на установленную клиентскую сборку; ввод и отрисовка не запускались.
- `NATIVE_UI` — используется исходный интерфейс движка; интерактивная проверка не выполнена.
- `ROUND` — самостоятельное действие редактора заменено действием над идущим раундом.
- `STANDALONE` — управление локальным контентом или переходом в другой игровой мир остаётся в самостоятельном редакторе.

## Контракт общего мира

`INet` доставляет сообщения канала `pp.subeditor.v5`. Сервер владеет ревизиями и историей. Все клиенты применяют подтверждённые операции через `FrameApplier` и `EntityOps`; оригинальный интерфейс создаёт запросы через `CommandBridge` и трекеры. Клиентские предварительные экземпляры спавна удаляются до применения заменяющего кадра, чтобы не занимать ID и разъёмы проводки.

В XML координаты принадлежат явно указанному владельцу `ppSubmarine`: 0 — главная подлодка, 65535 — мировой фрейм, остальные значения — ID самостоятельных подлодок. `HiddenSubPosition` не передаётся. Трансформации, отражение и снимки сохраняют владельца. ID сущностей сервер резервирует сверху диапазона 1..32767; повторная загрузка использует точные ID. Перенумерация действует только для соответствующего экземпляра `IdRemap` в области загрузки.

Для `SpawnSub` создаётся настоящий `Submarine`, его `SubmarineBody`, пространственная сетка и окно ID. Исходный `LoadSub` и перетаскивание файла перенаправлены в эту операцию. Изменение Hull и геометрии обновляет штатные границы, сетку и фикстуры, сохраняя существующее тело Farseer и его скорость.

## Границы протокола

Запрос операции ограничен 48 КиБ, снимок — 64 МиБ; число затронутых ID в кадре — 4096. Крупные действия не разбиваются автоматически на произвольное число независимых ревизий. Отказ восстанавливает локальное предварительное изменение и при необходимости запускает получение авторитетного снимка. Старый канал v4 несовместим: сервер и все клиенты должны использовать обновлённый пакет.

Функции изменения файлов пакетов, Workshop и запуска другого тестового раунда не объявляются реализованными сетевыми операциями. Работу всего интерфейса оригинала в игре этот реестр не подтверждает.
