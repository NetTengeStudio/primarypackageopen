# Проверка Live Editor и GM-сообщений

Дата отчёта: 2 ноября 2026. Схема возможностей: **5**, клиент и сервер обновляются вместе.

**Полное ТЗ: FAIL / не завершено.** Создание/удаление/клонирование связанной геометрии, провода, поворот/resize, полноценный каталог строительства и SpawnSub отсутствуют. Работоспособность полного редактора 1:1 в мультиплеере не заявляется. Архитектура и точные границы: [LIVE_EDITOR_ARCHITECTURE.md](LIVE_EDITOR_ARCHITECTURE.md).

Игра и dedicated server не запускались по инструкции пользователя. `PASS` ниже относится к конкретной офлайн-проверке, а не к игровой приёмке.

## Воспроизведение и доказательства

Из Primary package:

```powershell
pwsh -NoProfile -File Tools/verify_live_editor.ps1
```

Скрипт исполняет сборки, production-core регрессии, native metadata/IL/codec contracts, content/physics contracts, анализ сохранённых sync-логов, статические аудиты и git diff --check. Native entry point игры не вызывается.

Логи и DLL: `C:/Steam/steamapps/common/Barotrauma/Docs/PrimaryPackage/LiveEditor/`. `verification.json` содержит SHA-256 исходников, тестов, инструментов, сборок и отчётов. Время последнего полного прохода UTC: `2026-11-02T11:35:21.960890+00:00`. Тесты содержат численные выборки; их количество не равно количеству независимых игровых сценариев.
