# Интерфейс: сохранённый визуальный язык и открытая приёмка

Режим интерфейса — Operate: GM выбирает участника, связывает объекты мира, задаёт условие и последовательность действий, проверяет и отменяет исполняемые сцены. Основная информация — объект, цель, время и результат. Технические идентификаторы ресурсов не вводятся в поля действий вручную.

Применён существующий Primary GUI Engine. Сверка `GUIRenderer.cs: GUITheme` с `scpitdcode/CSharp/Client/Ui/Retro.cs` подтверждает соответствующие токены: чёрная панель с alpha 236, края 105/160, текст 200, вторичный текст 125, акцент 232/176/72; края 3, зазор 1, отступ 6, строки 22, кнопки 24. Эта работа не вводит отдельную тему и не импортирует UI GM Menu.

Редактор разделяет привязки, последовательность действий и параметры выбранного действия. Список серверных сцен и список выданных эффектов отдельны от черновика. Выбор точки временно скрывает рабочее окно, не уничтожая его; Escape возвращает окно. Повторяющиеся действия сохраняются как параметризованный пресет. Реальные существа явно отделены от персонального представления.

При статическом проходе проверены использование видимости окна в вводе/рендере, восстановление после выбора точки, очистка в конце раунда, права, выбранная строка, изменение кэшированных строк, ошибка загрузки ресурсов и отключение цели. Это не визуальная приёмка.

**Визуальная приёмка открыта.** Снимков production GUI и полного рендера галлюцинаций нет. Игра не запускалась по инструкции пользователя. Независимый обзор интерфейса не проводился; делегирование не запрашивалось. Нельзя подтвердить отсутствие обрезания текста, точность анимации конечностей, фактический контраст на игровом фоне, удобство в низком разрешении, LOS, освещение, голос и задержку ввода без соответствующих кадров и испытаний. Статический проход не получил статуса `ship`.
